# Noter

M5 Forbrændingsmotoranlæg (10 ECTS) giver grundlæggende indsigt i drift af forbrændingsmotoranlæg og hjælpesystemer: energiomsætning, drift, sikkerhed, økonomi og miljø.

## Eksamen

- Individuel mundtlig prøve på 20 minutter, uden forberedelsestid, med kendte spørgsmål ud fra læringsmålene og simulatorøvelserne.
- Hjælpemidler: lommeregner og formelsamling. 7-trinsskala, intern bedømmelse.
- **Forudsætning for eksamen:** obligatoriske opgaver (simulatorøvelse B, C, D og E = obligatorisk opgave 1–4) afleveret og godkendt, samt deltagelse i ekskursioner (fx Everllence PrimeServ, Diesel House, skibsbesøg).

> **Til den mundtlige prøve**
> Øv dig i at tegne systemerne fra hukommelsen (brændstof, smøreolie, kølevand, kedel, starteluft) og forklare dem højt på 3–4 minutter. Brug "Test dig selv"-spørgsmålene under hvert emne som eksamensspørgsmål.

## Læringsmål

**Viden og forståelse, du skal kende:**

- Energiomsætningen fra brændstof til akseleffekt: kemiske reaktioner, termodynamik, forbrug, emissioner, virkningsgrader.
- Hjælpesystemerne: smøreolie, kølevand, starteluft, forbrændingsluft, turbolader, udstødningsgas og brændselsolie (opbygning, virkemåde, betjening, fejlsøgning, vedligehold).
- Arbejdsprincip: luftskifte, trunk, krydshoved, trykladning.
- Oliers oprindelse, fremstilling, egenskaber og miljøpåvirkning.
- Motorens opbygning: stempel, plejlstang, krumtap, topdæksel med ventiler.
- Udstødningsgaskedel, brændstofindsprøjtningssystemer, tegningsforståelse, hydraulik- og pneumatiksystemer.

**Færdigheder, du skal kunne:**

- Analysere og bedømme forbrændingsprocessen.
- Beregne nøgletal: effekt, middeltryk, forbrug, emission, virkningsgrader, varmegenvinding.
- Starte, drive og evaluere et simuleret dieselmotoranlæg (Kongsberg).
- Analysere anlæg ud fra konstruktions- og procestegninger.
- Lave simple hydrauliske beregninger.

**Litteratur:** Skibsmotorlære 4. udg. (Jørn Wetterberg, JW) · Hydraulik for driftsteknikere 4. udg. (Leif Terkelsen, LT) · Motorlære Kompendium v2.6 (Michael Winther, MW) · Kompendier (K) · Opgavesamlinger.

# Formler

Alle formler fra kompendierne samlet ét sted. Forklaringerne står under hvert emne.

### Forbrænding og moment
```
C + O₂ → CO₂          4H + O₂ → 2H₂O
M = F · a             Effekt = M · ω          ω = 2π·n / 60
```

### Pumper og tryk
```
Q = D · n             D = deplacement pr. omdrejning
p = ρ · g · H         H = væskesøjlens højde
```

### Turbolader (G = gas, A = luft)
```
P_T    = ṁ_G · (h₁,T – h₂,T) = ṁ_G · c_p,G · (t₁,T – t₂,T)
P_is,T = ṁ_G · (h₁,T – h₂,is,T)            η_is,T = P_T / P_is,T
P_C    = ṁ_A · (h₂,C – h₁,C) = ṁ_A · (h₂,is,C – h₁,C) / η_is,C
P_is,C = ṁ_A · (h₂,is,C – h₁,C)            η_is,C = P_is,C / P_C
η_m    = P_C / P_T                         η_tot  = P_is,C / P_is,T
```

### Centrifuger
```
V_g = d² · (ρ_p – ρ_v) / (18 · η) · g      d i m, η i kg/m·s
a   = r · ω²       Z = r · ω² / g          V = V_g · Z
```

### Kedler
```
P_røg       = ṁ_røg · c_p,røg · (t_ind – t_ud)       c_p,røg ≈ 1,03–1,06 kJ/kg·K
P_kedel     = ṁ_damp · (h_afg – h_f)                 h_f = fødevand
η_kedel     = P_kedel / P_tilført
P_brændstof = ṁ_brændstof · h_i                      h_i = nedre brændværdi
P_røgtab    = ṁ_røg · c_p,røg · (t_røg,ud – t_luft,ind)
Q           = U · A · Δt_m
h_x         = h′ + x · r                             x = tørhedsgrad
```

### Hydraulik
```
P = Δp · Q            effekt afsat i en ventil
```

Formler til ydelse, middeltryk, fyldningsgrad, brændværdi, luftforbrug, energifordeling og emissioner står i Michael Winthers Motorlære Kompendium (MW kap. 1–8), ikke i disse kompendier.
